# DPG subset QA viewer

Generated from post-hoc reward alignment outputs.

Files:
- `subset_image_qa_all_steps.jsonl`: all steps [500, 1000, 1500, 2000, 3000, 3900], task1 for `gen`, task3 for `correction_0/1`.
- `subset_image_qa_all_steps.csv`: compact table with benchmark/reward QA as text.
- `subset_image_qa_2000_vs_3900.html`: side-by-side visual report sorted by benchmark drop.

Open the HTML in a browser on the same machine. Image paths are linked with `file://`.
